# Méthodologie — extension ESCO sans expert

Les codes ISCO ont été sélectionnés automatiquement par proximité entre les
domaines des cours et les familles professionnelles ISCO-08. Aucun expert
pédagogique n'a validé cette correspondance. Les résultats doivent donc être
présentés comme une expérience exploratoire fondée sur une sélection
heuristique reproductible.

Le corpus historique ESCO est complété avec les relations métier-compétence
d'ESCO v1.2.0. Les doublons exacts sont supprimés. Le modèle ne reçoit aucun
alignement AC-AAD pendant le fine-tuning : ces annotations restent réservées à
l'évaluation finale.
