Classification des systèmes
 Linéarité

      Si x(t ) = a1 x1 (t ) + a2 x2 (t )      alors    y (t ) = a1S [ x1 (t )] + a2 S [ x2 (t )]
 Causalité
      La réponse du système ne peut pas se produire avant l'excitation qui l'engendre
      Conséquence : si x(t ) = 0 pour t < 0              alors      y (t ) = S [ x(t )] = 0 pour t < 0
 Invariance temporelle
      Un décalage temporel en entrée induit le même décalage en sortie. La réponse du
      système est invariante par translation dans le temps. Le système est dit alors invariant.
      Si   y (t ) = S [ x (t ) ]   alors   y (t − t0 ) = S [ x(t − t0 )]
 Stabilité
      Un système est dit stable si en réponse à une entrée bornée, sa sortie est bornée
      ∃ M x / x(t ) < M x ⇒ ∃ M y / y (t ) = S [ x(t )] < M y
      Système qui, perturbé, revient à son état
      initial après disparition de la perturbation
