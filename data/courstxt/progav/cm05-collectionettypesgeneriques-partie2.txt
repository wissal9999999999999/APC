Méthode générique

Utilisation & Syntaxe
Les méthodes génériques sont utilisées lorsque des dépendances existent
entre les types des arguments et/ou le type de retour. Dans le cas
contraire (un seul type de paramètre) la simple utilisation du joker suffit.
        <T> typeretour methode(paramètres) {
          // utilisation du type T comme un type normal
          // paramètre, variable locale, ...
        }


Problème classique                                                        (déjà évoqué précédemment)
       static void tableauVersCollection(Object[] tab, Collection<?> col) {
         for (Object o : tab)
           col.add(o) // ne compile pas
       }
       static void <T> tableauVersCollection(T[] tab, Collection<T> col) {
         for (T o : tab)
           col.add(o) // compile
       }

Utilisé par la 1◦ méthode, les objets à comparer doivent l’implémenter

public class AutoBoxing {                                                // les Integer de -127 à 127 sont figés
  static void methode(Integer i) {                                       // figé = immutable
    System.out.println("Integer␣:␣"+i);                                  Integer a120 = 120, b120 = 120;
  }                                                                      if (a120 == b120)
  static void methode(double d) {                                          System.out.println("Egal");
    System.out.println("double␣:␣"+d);                                   else
  }                                                                        System.out.println("Non␣egal");

  public static void main(String[] args) {
    Integer i1=10;                                                       Integer a127 = 127, b127 = 127;
    int i2=i1;                                                           if (a127 == b127 && a127+100 == b127+100)
                                                                           System.out.println("Egal");
   // 10 autoboxing/unboxing                                             else
   for (Integer i3=0; i3<10; i3++)                                         System.out.println("Non␣egal");
     System.out.println(i3);                                         }
   // pour compatibilité avec les JDK précédents              }
   // => double : 5.0
   methode(5);

   Integer a256 = 256, b256 = 256;

Exemple générique

ProcessElements                                                                                        (source Oracle)

    class ProcessElements {
        public static <X, Y> void processElements(
            Iterable<X> source,
            Predicate<X> tester,
            Function <X, Y> mapper,
            Consumer<Y> block) {
                for (X p : source) {
                     if (tester.test(p)) {
                         Y data = mapper.apply(p);
                         block.accept(data);
                    }
                }
            }
    }



Exemple d’utilisation
    ProcessElements.processElements(liste,
                                    i -> i.getGenre() == Genre.HOMME,
                                    i-> i.getType(),

Comparaison ProcessElements vs Agrégats                                                                 (source Oracle)




Comparaison
  ProcessElements                           Agrégats
  source d’éléments (collection)          Stream<E> stream()
  sélectionner les éléments              Stream<T> filter(Predicate<? super T> predicate)
  obtenir une valeur liée à l’élément   <R> Stream<R> map(Function<? super T,? extends R> mapper)
  effectuer une action sur la valeur        void forEach(Consumer<? super T> action)

Stream : une séquence d’éléments, il ne s’agit pas d’une structure de données
comme les collections.
filter, map et forEach sont des opérations d’agrégat, opérations qui sont
effectuées sur des Stream.
L’ensemble forme un ≪ pipeline ≫ d’opérations
Utilisation possible des lambda expressions
